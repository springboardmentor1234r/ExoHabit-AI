# Frontend

The React frontend source code lives in the project root (`src/`, `public/`, `index.html`) as required by Vite's build system.

## Key Directories

- `src/pages/` — Page-level components (Index, Predict, Rankings, Dashboard)
- `src/components/` — Reusable UI components (Navbar, shadcn/ui)
- `src/lib/` — Utilities and mock data
- `src/assets/` — Static assets (images)

## Development

```bash
npm install
npm run dev
```

The dev server runs on `http://localhost:8080`.
